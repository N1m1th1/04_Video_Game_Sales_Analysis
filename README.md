**VIDEO GAME SALES ANALYSIS**


**ABOUT THE PROJECT**

This project focuses on analyzing video game sales data using Excel and Power BI.

The analysis explores global video game sales across different gaming platforms, genres, and years.

Excel was used for data analysis, pivot tables, pivot charts, and dashboard creation, while Power BI was used to create an interactive sales dashboard.
